# MaxCare Reception Assistant (Chrome Extension)

مساعد موظف الاستقبال: يتعرف تلقائياً على المريض المفتوح في نظام المشفى (MAXCARE / Solver WebHIS)،
يجلب بيانات تأمينه من السيرفر: موقع شركة التأمين يُشغَّل على السيرفر (playwright) لا على جهاز الموظف، والنتيجة مستند PDF يُطبع داخل صفحة المشفى مباشرة.

## التثبيت (وضع المطوّر)

1. افتح Chrome على `chrome://extensions`
2. فعّل **Developer mode**
3. اضغط **Load unpacked** واختر مجلد `Extension/` هذا
4. لا حاجة لأي بيانات دخول لكل موظف:
   - **عنوان السيرفر** مقيَّد LAN في الكود (`http://maxcall.local:3001`) — نشر التحديثات ذري (dual).
   - بيانات المستخدمين ليس مطلوبة في الإضافة؛ السيرفر هو من يشغل جلسات التأمين وعناوينها.

## الاستخدام اليومي

1. الموظف يعمل كالمعتاد على صفحة تسجيل المريض في المشفى
2. ينقر أيقونة الإضافة → يظهر اسم المريض ورقم بطاقة التأمين تلقائياً
   (يقرأهما من مكونات صفحة `app-patient-details` — وإن لم يظهرا: إدخال رقم الملف يدوياً)
3. يختار **النوع** (Out-Patient افتراضياً — Dental وغيرها عند الحاجة)
4. زر **"طباعة مستند التأمين"** → تضغط، يظهر تقدّم في أعلى صفحة المشفى (Signing in… → Eligibility… → Done) بينما السيرفر يعمل بصمت على مكان آخر، ثم تُعرض طباعة المستند داخل صفحة المشفى مباشرة
5. عند اختيار MedNet، موقع MedNet لا يُفتح على جهاز الموظف إطلاقاً في هذه المرحلة

**عند أي مشكلة:** زر "📋 نسخ السجل" في أسفل الـpopup ينسخ سجلاً تشخيصياً كاملاً
(بلا كلمات مرور) — أرسله للمطور ليحلل المشكلة بدقة.

## خريطة الملفات

| المسار | الدور |
|---|---|
| `manifest.json` | تعريف الإضافة MV3: الصلاحيات، السكربتات، الأيقونات |
| `src/background.js` | منسّق العمليات: جلب البيانات، إدارة تبويب التأمين، إعادة الإرسال بعد كل تنقل |
| `src/lib/settings.js` | الإعدادات المخزنة في `chrome.storage.local` (بما فيها كلمات المرور — لا تُكتب في الكود أبداً) |
| `src/lib/server.js` | عميل `/api/his/patient/<id>` على سيرفر MaxCare |
| `src/lib/insurers.js` | سجل الشركات المدعومة + مطابقة اسم الدافع من HIS + أنواع استعلام NextCare |
| `src/lib/log.js` | السجل التشخيصي (ring buffer في storage.session — بلا أسرار) |
| `src/content/his-reader.js` | قراءة المريض/رقم البطاقة/اسم التأمين من صفحة المشفى (عند الطلب فقط) |
| `src/content/bridge.js` | أدوات مشتركة داخل صفحات التأمين: تعبئة/نقر/انتظار + لوحة الحالة + وضع الاستكشاف |
| `src/content/insurers/nextcare.js` | محوّل NextCare (ASP.NET WebForms) |
| `src/content/insurers/mednet.js` | محوّل MedNet (Oracle ADF) — أساس + وضع استكشاف |
| `src/popup/` | واجهة الموظف |
| `src/options/` | شاشة الإعدادات |
| `tools/build-update.py` | بناء حزمة التحديث التلقائي (CRX موقّع) ورفعها للسيرفر |
| `docs/` | التوثيق التفصيلي (معمارية، محولات، API السيرفر، اختبار، تحديثات) |
